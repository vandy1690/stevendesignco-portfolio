import data from '../../../data/components.json';

Every component lives at `src/components/ui/<Name>.astro` and is imported with a
relative path. This table is generated by `scripts/build-manifest.mjs` from the
components, so a component added to that folder appears here without anyone
editing this page, and the build fails if one of them has no documentation page
to point at.

The same data in machine-readable form is
[`custom-elements.json`](/custom-elements.json).

## Components you can import

{data.components.length} of them.

							: <span>composes other components</span>}

## Patterns that are CSS and markup only

These have a documented page and real, shipped classes, but no component to
import, so the markup gets written by hand each time. They are derived from the
pages no component claims, which is why this list cannot disagree with the one
above.
