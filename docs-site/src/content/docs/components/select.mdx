## Why the native element

The platform picker is better than anything we would build: it is the control
the visitor already knows, it works with a keyboard, it works with a screen
reader, and on a phone it opens the system wheel rather than a list that scrolls
inside a scrolling page. A custom dropdown has to re-earn all of that and
usually does not.

So only the chrome is ours: the same height, border, radius and background as a
text input, because the two sit next to each other and a mismatch reads as a
mistake. The extra inline-end padding leaves room for the platform's own arrow.

## In code

`src/components/ui/Select.astro`.

```astro
---
import Select from '../../components/ui/Select.astro';
---
<div class="sdc-field">
	<label class="sdc-field__label" for="heard">How did you hear about me?</label>
	<Select
		id="heard"
		name="heard"
		options={[
			{ value: '', label: 'Pick one' },
			{ value: 'referral', label: 'Someone referred me' },
			{ value: 'search', label: 'I searched for it' },
		]}
	/>
</div>
```

The label's `for` matches the Select's `id`, which is what gives the control its
name. To show an error, add `sdc-field--invalid` to the wrapper, which draws the
error border, put the message in a `<p class="sdc-field__error" id="heard-err">`
after the Select, and pass `invalid` and `describedBy="heard-err"` so the
failure is announced.

| Prop | Type | Default | What it does |
| --- | --- | --- | --- |
| `id` | string | required | Ties the label's `for` to this control |
| `name` | string | none | The form field name |
| `options` | `{ value, label }[]` | required | In display order. A `value` of `''` becomes a disabled placeholder row |
| `value` | string | none | Which option starts selected |
| `required` | boolean | `false` | Marks it required |
| `disabled` | boolean | `false` | Greys it out |
| `invalid` | boolean | `false` | Sets `aria-invalid`. The `sdc-field--invalid` wrapper draws the border |
| `describedBy` | string | none | The id of the hint or error describing it |

## Checks before you ship

1. It has a visible label whose `for` matches the Select's `id`.
2. The placeholder row is disabled, so it cannot be submitted as an answer.
3. It is not being used for fewer than about four options.
