## Why this exists

A design system is only as good as the next person's ability to use it
correctly without being told. This documentation is the test of that: every component
answers the same three questions, in the same order, in language that does not
assume you write CSS.

## What is documented elsewhere

This site does not repeat the token values or render live components. The
[Storybook](https://stevendesignco.com/labs/sdc-storybook/) does both, and it
generates its stylesheet from the running site, so it cannot drift. When you
need to see a component working, go there. When you need to know whether to use
it, stay here.
